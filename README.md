# Сравнение результатов поверок газоанализаторов

Пример для ALTAIR 4XR и ЭРИС-414 по открытым записям ФГИС «Аршин» за 2023–2025 годы. Откройте `index.html` для просмотра отчёта. В каталоге `dannye` лежат результаты по годам и таблица по 48 группам «поверитель и год».

```sh
python check_summary.py
```

Эта команда пересчитывает сводный результат по опубликованной таблице без интернета. Исходный корпус содержал 64 776 записей. Для детальной выборки разобраны 416 карточек, из них 410 периодических поверок. Результаты относятся к отобранным группам. Различие исходов само по себе не устанавливает причину отказа прибора.

Для новой выгрузки с сайта «Аршин» запустите последовательно `python raschet.py` и `python vladeltsy.py`. Понадобится интернет. Исторические карточки реестра доступны у первоисточника, ссылки на запросы приведены в отчёте. Текущий ответ реестра может отличаться от сохранённых итогов.
